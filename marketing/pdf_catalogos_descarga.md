### Cómo subirlos (2 opciones)
1) Admin → Centro de Descargas → Subir → selecciona el PDF y rellena título/categoría → Queda visible para usuarios aprobados.
2) Admin → Centro de Descargas → Enlace externo (si prefieres no pesar el hosting y simplemente enlazar al PDF del fabricante).

### Naming sugerido internamente
Para no repetir nombres ni confundir, usa títulos como "Tarifa 2026 – [Marca] (PDF)" y categoría "Catalogos".

Si quieres, puedo añadir en `/catalogos` cada PDF real una vez subidos (los rotulos ya están separados por marca). Solo dime los que quieres incluir.
